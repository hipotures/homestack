Buttons

.ds-btn (secondary) with .ds-btn-primary, .ds-btn-ghost, .ds-btn-danger, .ds-btn-compact; .ds-icon-btn needs an aria-label. Disabled uses the native attribute.

An inline <svg aria-hidden="true"> child sits next to the label. Applications whose body text is larger than their controls set --ds-control-font-size.

Badges and status
